Manny quick start

Requirements

    Windows x64
    Visual Studio C++ build tools
    clang-cl available from the command line

From the unpacked release directory, run:

    cd hello
    ..\manny.exe

Manny compiles and links the example. Run it with:

    ..\manny.exe run

Run the build again to see the no-op case:

    ..\manny.exe

Then edit message.h or message.c and ask Manny to explain the next build:

    ..\manny.exe --explain

The build description is build.elf. Manny's persistent incremental state lives
in .manny/state, generated files live in build, and the C target helpers live in
..\c.elf.
